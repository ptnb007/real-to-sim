# Astra 房间网格重建→Isaac Sim

## 目标

用手机多视角照片建立一个可编辑的房间网格，经 Blender 整理后导出 USD，最终在 Isaac Sim 中放入 Galaxea R1 Pro，验证移动、碰撞和人体搜索。

## 目录

- `input_photos/`：原始房间照片。
- `output_mesh/`：重建得到的 GLB/OBJ 及纹理。
- `isaac_usd/`：经尺度、地面和碰撞修正后的 USD 场景。

## 拍摄要求

1. 建议先拍一个小房间，横屏 12–20 张。
2. 相邻照片保持约 60% 重叠，按同一方向绕房间一圈。
3. 要拍到墙角、地面边界、门和主要家具；避免人员走动、镜面和大面积过曝。
4. 保持同一镜头和焦段，不使用人像或超广角模式。
5. 额外量一条真实长度（例如门宽 0.90 m），用来恢复米制尺度。

## 验收条件

- Blender 中可正常打开，没有大块飘浮网格。
- 地面水平，一条已知尺寸的误差尽量控制在 5% 内。
- 视觉网格与简化碰撞网格分离。
- Isaac Sim 中机器人不穿地、不穿墙，能在房间中运动。

> 注意：Astra 可辅助理解照片、生成/整理 Blender 场景和自动化导出，但随手拍照不能保证量测级几何准确度。用于机器人仿真时，必须额外校正尺度、地面和碰撞体。
