# 机器人实验室：真实三维网格 + 离线交互网页

## 先打开网页

双击 `robot_lab_viewer.html`，用桌面版 Chrome 或 Edge 打开。
这是一个自包含 HTML：程序、GLB、贴图和参考照片全部内嵌。无需安装 Python、启动服务器、访问 CDN 或填写 API key。聊天窗口的附件预览不一定执行 HTML；请把文件保存到本机后打开。

网页使用 WebGL 2。浏览器未启用图形加速时会给出错误提示；这时可在浏览器设置中启用图形加速后重新打开。

| 操作 | 功能 |
| --- | --- |
| 左键按住拖动 | 围绕当前观察中心旋转 |
| 滚轮 | 放大 / 缩小 |
| 右键按住拖动 | 平移观察视角 |
| 单击物件或左侧列表 | 选择独立物件，显示其模型范围与说明 |
| 双击物件，或选中后按 F | 聚焦物件 |
| G / 右侧移动工具 | 按住物件在水平面拖动 |
| O | 返回旋转观察模式 |
| M | 依次选择两个三维表面点，测量模型距离 |
| W | 网格线开关 |
| 1 / 2 / 3 | 整体 / 照片参考 / 俯视视角 |
| Esc | 取消选择、关闭弹窗，返回观察模式 |
| 导出 GLB | 保存当前物件位置和整体尺度，所有模型几何体均保留 |
| 保存布局 | 保存 JSON；把这个 JSON 拖回网页可恢复布局 |

物件移动是编辑操作，不运行碰撞、重力或支撑检测。移动工作桌时，其关联桌面袋子 / 小物件一起移动；桌下独立收纳箱不会自动跟随。墙体和地板不可拖动。
显示 / 隐藏和吊顶剖开仅影响网页查看，不会从导出的 GLB 中删除几何体。

## 交付文件

- `robot_lab_viewer.html`：可离线使用的交互网页。
- `robot_lab.glb`：包含 28 个可选物件组、100 个材质 / 碰撞分组网格、48,834 个三角面的三维场景。贴图全部内嵌，坐标为 Y 向上。
- `robot_lab.usda`：同一场景的原生 USD ASCII 文件；米为单位、Z 向上；含 34 个静态碰撞网格。
- `textures/`：USD 使用的相对路径贴图；不要只拷走 USDA 而漏掉本文件夹。
- `references/`：用户上传照片的缩小副本，供检查对应关系。原照片可能包含机器人 / 人物，但它们没有被建入三维模型。
- `scene_manifest.json`：物件、材料、模型范围、估计尺度及限制说明。
- `apply_layout_to_usd.py`：将网页保存的布局与整体尺度写入另一份 USD，原文件不被覆盖。
- `source/build_scene.py`：近似几何体建模和 GLB / USD 导出的源代码。
- `source/viewer_template.html`、`source/assemble_viewer.py`：网页源文件与打包程序。
- `docs/validation_report.json`：实际执行过的格式与浏览器交互检查记录。
- `viewer_preview.png`：网页中真实三维渲染的截图，不是另行生成的效果图。

## 在 Isaac Sim 中使用

完整解压后，在 Isaac Sim 中打开 `robot_lab.usda`。保留同目录的 `textures/`。
模型的竖直轴是 Z，单位是米。USD 的静态碰撞体主要覆盖地板、墙体、桌板、桌腿、隔断、显示屏与容器等环境物体。

**本次没有在 Isaac Sim / PhysX 中实际运行验证，也没有使用 OpenUSD SDK 进行模式校验。** 已检查 GLB 的独立解析、有限数值、三角面索引与嵌入贴图，并测试网页旋转、缩放、平移、物件拖动、布局保存、尺度设置和编辑后的 GLB 导出。USD 已检查结构和资产路径，但应在目标 Isaac Sim 版本中再次检查加载警告、碰撞可视化及物理行为。

如果已有机器人 USD，可以在验证场景之后再添加；本交付不包含任何机器人模型。

### 网页编辑后，同步到 USD

在网页点击「保存布局」，得到 `lab_layout.json`。在此文件夹执行：

```bash
python apply_layout_to_usd.py /path/to/lab_layout.json
```

输出为 `robot_lab_edited.usda`。该脚本只使用 Python 标准库，会把 Y-up 的位移转换为 Z-up。显示 / 隐藏状态不写入 USD，以免误删环境物体。

## 重要：这不是实测高精度重建

这是**根据原始照片人工参数化搭建、局部使用照片纹理的近似三维场景**，没有执行 SfM / MVS、神经重建、单目深度估计或 3D Gaussian Splatting，也不是已标定数字孪生。

已去除机器人，保留主要非机器人家具与物品的对应关系：两张桌子、深灰桌布、带标牌的隔断、两台显示屏及支架、卷帘与通风口、海报墙、纸袋 / 布袋、收纳箱、垃圾桶、椅子、脚踏开关、路由器、可见线缆及胶带等。细小杂物、背面、遮挡区、材料细节和数量细节做了简化，因此不能保证“所有其他物体”的逐件精确恢复。

没有相机标定、相机位姿、深度或任何实测长度。初始模型以**桌高 0.75 m 为建模假设**，不是对真实桌高的判断。网页的模型范围和测距均不能当作房间实测尺寸。输入实测桌高只能修正整体尺度，不能修正各物件的比例误差。

仅建立了照片覆盖的房间角落，模型外沿是裁切范围，不是对真实房间边界的推断。未拍到的左 / 前墙不补成一个假设的封闭房间。默认隐藏吊顶是为了方便观察，不表示现实中移除结构。

纸袋、布袋、桌布和线缆仅为静态视觉网格，没有柔体物理。桌面小件没有设置动态刚体、质量、惯量或经过校准的抓取碰撞几何。网页光照与 Isaac Sim 的渲染不会完全一致。

### 正式移动抓取数采前需要完成

先测量并校准桌高、桌面尺寸、通道宽度和相对位置。随后检查碰撞与接触面，把目标物件拆成适合抓取的独立刚体，设置经确认的质量 / 惯量、摩擦、语义标签，以及相机与机器人坐标关系。检查深度图、碰撞穿透、支撑、抓取稳定性和各观察角度的视觉差异，再开展数采。

本版适合作为可编辑场景初稿、布局检查和资产导入流程的起点；不能直接代表真实场景中的抓取效果或数据分布。

## 重建交付文件（可选）

仅查看网页和导入 GLB / USD 不需要这些依赖。修改建模源代码时才需要：

```bash
pip install numpy scipy Pillow opencv-python trimesh
python source/build_scene.py
python source/assemble_viewer.py
```

脚本使用固定随机种子。模型参数位于 `source/build_scene.py`；可用实测值替换假设尺寸。该交付不包含任何字体文件，不依赖远程 JavaScript 库，也不会将照片或模型上传到外部服务。
