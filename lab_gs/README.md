# 实验室局部 3DGS 重建

## 用户指定的范围

白色折叠挡板、紫色挡板与前方桌子（桌面放紫色托盘）之间的空间。目标是保留这些静态边界和中间地面。

## 实际素材与位姿结果

本次使用当前提供的 9 张 JPG，不复用以前训练的实验室 PLY，不使用生成式补图。

1. 相同分辨率、共享 SIMPLE_RADIAL 内参：9 张中注册 3 张，122 个稀疏点，平均重投影误差 0.378 像素。
2. 原始分辨率、各图独立 SIMPLE_RADIAL 内参：9 张中注册 5 张，232 个稀疏点，平均重投影误差 0.494 像素。

第二种结果用作局部 GS 草稿的训练输入。对应照片覆盖紫色挡板、机器人及桌子一侧。白色挡板的 3 张照片没有注册，另有一张电视/红椅照片也未注册。

这意味着目前没有恢复出用户指定的完整区域，尤其没有把白色挡板与紫色挡板可靠地接到同一坐标系中。重投影误差小不代表场景完整，也不代表实际尺寸准确。

## GS 草稿

训练采用实际 COLMAP 相机位姿及稀疏点初始化，使用 gsplat 可微光栅化、L1/SSIM 损失和官方 DefaultStrategy 增密/裁剪。训练前按求解出的径向畸变参数去畸变为针孔视图。

- 5 个注册视角；训练分辨率 640×480。
- 3,000 次优化，SH0；种子 42。
- 模型与报告见 partial_gs/。
- partial_training_comparison.png：左为去畸变后的输入，右为训练视角渲染。不是留出视角测试。
- lab_partial.ply：标准 Gaussian PLY，不是三角网格，没有碰撞体。
- checkpoint.pt：Gaussian 参数快照，不包含完整优化器状态。
- 坐标经过数值归一化，尺度未标定为米。

视觉验收未通过：训练视角仍有明显黑色空洞、漂浮与条纹状 Gaussian。当前不是可用重建结果，不能作为完整导航环境验收。人物与机器人没有语义剔除，可能成为静态外观；它们遮住的区域没有被补造。详见 partial_gs/quality_check.json。

## 下一步所需的补拍

沿“白色挡板前 → 中间地面 → 紫色挡板前 → 前方桌子”的连续路线移动拍摄。相邻画面同时保留前一处的特征和后一处的特征；不要只在原地转动相机。对地面、挡板底部、桌腿增加有平移的斜视角；尽量保持人和机器人不移动。一次连续视频比互不衔接的几个远景更适合补足当前缺口。

加入一段已知长度（例如实测挡板宽度或两处地面标记间距），便于重建后标定真实尺度。不要从照片目测尺寸作为物理仿真依据。

## 文件

- input/：9 张原始输入。
- source_map.json：第一轮预处理图名与原图的对应关系。
- sparse/：第一轮位姿结果。
- sparse_independent/：第二轮位姿结果，用于草稿训练。
- sfm_report.json / sfm_independent_report.json：两轮实际报告。
- train_partial.py：训练与导出脚本。
- partial_gs/report.json：训练结果与限制。

本机运行依赖 D:/isaacsim-5.1.0 的 Python/PyTorch，pycolmap 3.13.0，gs_isaac 中已验证的 gsplat 1.5.3 预编译内核。run_python.bat 只启动该环境，不需要启动 Isaac GUI。
